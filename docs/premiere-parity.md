# Wabcut 0.5 and Premiere Pro: what matches, what doesn't

This compares Wabcut 0.5.0 (26 October 2026) with Premiere Pro on Windows. The 0.1 rows were measured against Wabcut
0.1.0 "First Cut" (tag `v0.1.0`) and 0.1.2; rows marked **(0.2)** were added or changed by the 0.2 parity work of
15 to 22 October 2026, rows marked **(0.4)** by the 0.4 work of 24 and 25 October 2026, and rows marked **(0.5)** by
the 0.5 work of 26 October 2026. The Premiere version is 26.5, released September 2026, as listed on Adobe's
[What's new in Premiere](https://helpx.adobe.com/premiere/desktop/whats-new/whats-new.html) page. It covers Wabcut's
three target uses: **gaming** videos (long-form and Shorts), **video essays** and **documentaries**.

How to read it:

- Premiere's feature areas come from Adobe's own help pages, linked in each row.
- Each Wabcut status is backed by evidence from this repository: a Catch2 test name or test file under `tests/`, or a
  step of the 0.1 release run ("RC.2", workflows **a** gaming, **b** Shorts, **c** video essay, **d** documentary).
- **Equal** means Wabcut does the same job for the three uses, and the evidence shows it working. It does not mean
  every option matches; differences that matter are in the notes.
- **Better** is used only where the row names a concrete advantage.
- **Partial** names what is missing. **Missing** means not in Wabcut yet.
- In the AI rows, Equal means the feature exists and passes its tests. Real-footage quality has not been benchmarked
  against Premiere's.
- 0.2, 0.4 and 0.5 rows are verified by automated tests only. None of the 0.2, 0.4 or 0.5 features has been through
  a release run with real projects yet, and files exported for other applications (AAF, OMF, broadcast captions) have
  been checked with open-source readers, not yet in Pro Tools, Media Composer or Resolve.

Adobe's help site refused automated page fetches (HTTP 403) on 2026-10-13 and 2026-10-15. The Premiere side was
therefore taken from the same help pages as a search engine indexed them. Re-open a link before quoting it externally.

## Where Premiere is still ahead

- **Platforms and maturity.** Wabcut is made and tested on Windows (the Linux and macOS builds are previews), not
  code-signed, and its update checks are opt-in (Help > Check for Updates…, or daily once turned on). Neither 1–3 hour
  recordings nor 120–240 fps sources have been benchmarked, and the 0.2 features have only been verified by automated
  tests. Premiere has had decades of production use on long, heavy projects.
- **Ecosystem.** Premiere has third-party video effect plug-ins (Wabcut has no OpenFX host yet), .mogrt templates
  from After Effects, Adobe Stock, the Film Impact library and Frame.io review with shared links and shared projects.
- **HDR finishing details.** Wabcut has colour management, HDR masters and (0.6) Minimal Tone Mapping, gamut
  compression, an output colour space and SDR Conform, but not Premiere's own tone-mapping methods or every camera log
  space.
- **Hand-off to audio post and broadcast.** AAF, OMF, broadcast caption files and (0.6) MXF OP1a / OP-Atom with
  embedded CEA-608 / 708 are written and checked with FFmpeg's readers, but not yet proven in Pro Tools, Media Composer
  or a broadcaster's QC.
- **Stabilization.** Warp Stabilizer's Subspace Warp is a per-frame perspective, not Premiere's mesh warp.
- **Caption details.** Spell check needs Windows (no macOS / Linux dictionaries yet).
- **Project panel and media.** VR / 360 is partial (0.7, [VR / 360 video](vr.md)). Several projects can be open, but items brought in from another
  project are copies, not live references; XMP goes into MP4 / MOV files only (other files keep a sidecar);
  RAW Source Settings have exposure and white balance only; R3D, BRAW and ARRIRAW need a decoder helper built with
  the vendor's SDK (none ships with Wabcut).
- **Missing AI features:** none that this list tracks; (0.2 added generated sound effects, Color Match face detection and
  automatic face redaction; 0.7 added the face-aware Morph Cut and AI Eye Contact, which Premiere does not have.)
- **Measured AI quality.** Premiere's AI features ship after Adobe's own evaluation. In Wabcut, real-footage quality for
  the local models (search, reframe, Enhance Speech, highlights, auto-tagging) and live cloud-provider runs have not
  been benchmarked. The numbers above come from synthetic or opt-in tests.

## Where Wabcut is ahead

- **Price.** Free and open source, with no account. AI runs locally or with your own key, with no credits, an exact
  price before each cloud call, and a per-project "no cloud" lock.
- **Privacy.** Redaction is anchored in the source, so it follows the footage everywhere, audio, captions and dubs
  included.
- **Gaming.** A local, explainable highlight finder, gameplay dead-time removal (also inside nested gameplay +
  facecam sequences), facecam layouts and versions, and presets for Discord file sizes.
- **Automation.** An editing assistant whose actions are all undoable commands, and a local MCP server; every 0.2
  feature is a typed command too.
- **Coming from other editors.** A Carried / Approximated / Dropped report when importing from Premiere, Resolve and
  Final Cut.
